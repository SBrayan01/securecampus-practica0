Simulador visual de seguridad móvil · sin instalar Android Studio

1. ¿Qué simulamos?

Una aplicación móvil que consume la API REST de SecureCampus. En esta página se estudia el almacenamiento local y la diferencia entre HTTP y HTTPS. No se guardan contraseñas ni tokens de sesión reales.

El valor DEMO-NO-ES-UN-TOKEN-REAL es un marcador ficticio. Este laboratorio solo debe usarse en 127.0.0.1.

2. Almacenamiento inseguro (simulación)

Guardar un marcador ficticio en localStorage sirve para observar que el navegador lo conserva después de recargar.

Sin comprobación todavía.

En una aplicación real, no almacenes contraseñas ni secretos de sesión en un almacenamiento legible desde JavaScript.

3. Sesión real protegida

SecureCampus utiliza una cookie de sesión HttpOnly. Este simulador no intenta leerla. La autorización se realiza en el servidor.

Inicia sesión previamente en la pestaña REST/GraphQL.

Abrir inicio de sesión y explorador REST/GraphQL

4. Comunicación cifrada: observar el protocolo

Sin comprobación todavía.

HTTP local: aceptable únicamente para esta demostración en la computadora de clase. HTTPS/TLS: obligatorio para transmitir credenciales y datos sensibles en entornos reales. No introduzcas credenciales reales.

5. Preguntas guiadas

  1. ¿Qué diferencia existe entre localStorage y una cookie de sesión HttpOnly?
  2. ¿Qué riesgos tendría guardar una contraseña real en el almacenamiento local?
  3. ¿Por qué no basta con ocultar el botón “Consultar” para proteger las calificaciones?
  4. ¿Qué cambia entre HTTP en localhost y HTTPS en producción?
